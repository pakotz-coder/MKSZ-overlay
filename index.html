Adj meg egy nevet (pl. a saját neved vagy a csapatod), és megkapod a két linkedet: a vezérlőt telefonra/laptopra és a kimenetet a streamelő szoftverbe. / Pick a room name and get your two links: the control page and the output page.

2 · A kimenet bekötése / Add the output to your stream

Yolobox / Yolobox Pro
1. Főképernyőn nyomd meg az Overlay (rétegek) gombot, majd Add Web Overlay / Webcím hozzáadása.
2. Illeszd be a Kimenet linket, méretezd teljes képernyőre.
3. A háttér automatikusan átlátszó — a grafika a kép fölött jelenik meg.
OBS Studio
1. Sources → + → Browser.
2. URL: a Kimenet link · Width 1920 · Height 1080.
3. Pipáld be: Shutdown source when not visible = KI, hogy folyamatosan élő maradjon. A háttér átlátszó.
vMix
1. Add Input → Web Browser.
2. URL: a Kimenet link · felbontás 1920×1080.
3. Tedd Overlay csatornára (pl. Overlay 1) — az átlátszóság automatikus.

3 · Meccsnap / Match day

1. Nyisd meg a Vezérlő linket telefonon vagy laptopon.
2. Illeszd be a mérkőzés livescore-linkjét (pl. livescore.mksz.hu/32021351777/esemenyek) és nyomd meg a Kapcsolódás gombot.
3. Ellenőrizd az előnézetben a csapatokat és az állást, majd nyomd meg a grafikák gombjait. Ennyi.
Több szoba = több egyidejű meccs, egymást nem zavarják. / Multiple rooms run multiple matches at once.
